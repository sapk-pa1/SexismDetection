# HEFT project documentation

This folder documents the whole pipeline: raw data, processed files, the analysis, LLM inference, batch runs and the final test evaluation. Everything here describes the repo as of **2026-10-23**. When code and docs disagree, the code wins; fix the doc and log the fix in [`experiment-log.md`](experiment-log.md).

> **Content warning.** The datasets contain sexist, offensive and violent language. No post text is quoted in these docs.

## The pipeline in one picture

```
raw files (data/CMSB, data/EDOS, data/EXIST, data/splits/cmsb_split_s42.csv)
   │  notebooks/01_data_prep.ipynb        hashes checked against results/data_manifest.json
   ▼
data/processed/{train,dev,test}/{cmsb,edos,exist}_{split}.parquet
   │                    │
   │                    └─ notebooks/02_data_analysis.ipynb   descriptive stats (test label-blind)
   ▼
run_inference.py  (one model × one task × one split; resumable)
   ▲   driven by notebooks/20_llm_runs.ipynb (15 models × 7 tasks, parallel on one GPU)
   │
   ▼
outputs/{run_name}/  config.json, environment.json, predictions.jsonl, complete.json, README.md
   │
   │  notebooks/99_final_eval.ipynb       the only place test labels are read
   ▼
results/final_eval/{tables,figures,paper}/, summary.json
outputs/20261020_all_all_llms_finaleval_s42/evall_submissions/   EXIST files for EvALL
   │
   ▼
docs/report/*.tex → PDF
```

## Glossary

| Term | Meaning here |
|---|---|
| **Task** | One (dataset, task key) pair from `configs/data_prep.yaml`, e.g. `edos/task_b`. There are 7. |
| **Binary / multiclass / multilabel** | Task types. Binary: one Yes/No. Multiclass: exactly one class (EDOS B/C, EXIST 1.2). Multilabel: any subset of classes (EXIST 1.3). |
| **Hard label** | One gold decision per post (the released label or the majority). |
| **Soft label** | Share of annotators choosing each class. Its meaning differs per dataset ([02](02-data-pipeline.md#soft-labels)). |
| **`text_norm`** | The normalised post text every model sees. `text` is the untouched original. |
| **Answer mass** | P(Yes)+P(No) for a Yes/No question, or the summed probability of all option letters for a lettered question. |
| **Soft refusal** | A label whose answer mass is below a threshold τ. Primary τ = 0.5 (fixed a priori). |
| **Strict scoring** | A refused, zero-mass or unparsed answer counts as wrong. |
| **Fair subset** | Posts that every compared model answered on every label (no refusal). |
| **Label-blind** | Reading a test file without its label columns. |
| **Run name** | `{date}_{dataset}_{task}_{model}_{method}_s{seed}`; one folder per run under `OUTPUT_ROOT`. |
| **Manifest** | `results/data_manifest.json`: SHA-256 of every raw input and a content hash of every processed file. |
| **EvALL** | The official EXIST evaluation service (https://evall.uned.es/). EXIST test gold is not public. |
